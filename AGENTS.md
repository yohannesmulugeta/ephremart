# Ephrem Tefera Portfolio — UI/UX Guidance

Use this file as a standing design brief for any AI coding agent working in this repository.

## Goal
Build and maintain a premium contemporary artist portfolio for Ephrem Tefera. The artwork must remain the main visual focus.

## Design direction
- Editorial, gallery-like, artistic, restrained.
- Warm ivory / paper backgrounds, deep navy, restrained gold accents.
- Strong serif display typography with clean sans-serif body copy.
- Use asymmetry and generous whitespace intentionally.
- Prefer large artwork and confident composition over decorative UI.

## UX priorities
- Mobile-first quality at 375px, 390px, 430px, 768px, 1024px and 1440px.
- Touch targets at least about 44px where practical.
- Keep navigation simple and fast.
- Preserve visible keyboard focus states.
- Respect reduced-motion preferences.
- Avoid clipped text, broken layouts and horizontal scrolling.
- Keep artwork lightbox usable by mouse, keyboard and touch/swipe.
- Use semantic HTML and meaningful alt text.

## Avoid
- Generic SaaS layouts.
- Purple AI gradients.
- Excessive glassmorphism.
- Too many cards or pills.
- Heavy 3D/WebGL that distracts from the paintings.
- Excessive rounded corners.
- Animation for animation's sake.
- Inventing artwork titles, dates, dimensions, prices, exhibitions or biography facts.

## Before merging visual changes
Audit:
1. Visual hierarchy
2. Typography and spacing rhythm
3. Artwork crop quality
4. Mobile navigation
5. Touch interactions
6. Keyboard accessibility
7. Contrast and readability
8. Image loading/performance
9. Responsive layout at the target widths above
10. Whether the change makes the portfolio feel more credible to collectors, galleries and curators

If a proposed effect competes with the artwork, remove or simplify the effect.

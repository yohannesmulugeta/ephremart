# Ephrem Tefera — Artist Portfolio

A contemporary portfolio website for Ethiopian visual artist Ephrem Tefera.

## Design direction

The first build uses a warm gallery palette, large artwork, editorial typography and asymmetrical compositions inspired by contemporary art-gallery interfaces while remaining specific to Ephrem's work.

## Current scope

- Homepage hero and selected works
- Visual-theme section
- Artist biography
- Education and recognition
- Selected exhibition venues
- Responsive desktop/mobile layout
- GitHub Pages deployment workflow

## Important content notes

- Artwork titles, dimensions, individual media and dates have intentionally not been invented. Add them only after they are confirmed by the artist.
- The uploaded portrait is intentionally not used in this first version.
- The organization name `UNFPI` is shown exactly as supplied and should be verified before the final public launch.
- Contact details and social links are intentionally omitted until confirmed.
